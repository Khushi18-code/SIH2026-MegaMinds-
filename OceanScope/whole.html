About OceanScope

OceanScope is a hackathon prototype for exploring ocean model output alongside real ARGO float and glider observations. It runs entirely on generated mock data structured to mirror NetCDF/CSV ocean datasets, so the same interface can later connect to live HYCOM output and the ARGO network.

Pipeline: Raw Data → Ingestion → Parsing → Validation → Normalization → Time Filtering → API → Frontend → 3D Visualization → Comparison → Analysis.
